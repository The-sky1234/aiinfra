# 课文伴读

装在你自己的 Chrome 或 Edge 里。你先登录 EverythingAI 并打开某一课，它读取**当前屏幕**上的课件图，用你自己的视觉模型讲通俗中文。

它不会要课程网站的密码，也不会再占一个设备名额。云端助手看不到你已经登录的那个标签，所以读取必须发生在你这台浏览器里。

## 安装

1. 下载这个 `lesson-companion` 文件夹。
2. 打开 `chrome://extensions`（Edge 是 `edge://extensions`）。
3. 打开右上角的「开发者模式」。
4. 点「加载已解压的扩展程序」，选中 `lesson-companion` 文件夹。
5. 打开课文正文，例如第 4 课，再点工具栏里的「课文伴读」。

## 第一次使用

1. 在侧栏里选一个**能看图**的模型。纯文本模型读不了课件。
2. 预设里有 OpenAI、通义千问，以及本机 Ollama。选「自己填」时，接口要兼容 OpenAI 的 `/chat/completions`。
3. 点「保存」。浏览器会询问是否允许扩展访问那个模型接口。
4. 回到课文页，点「讲解这一屏」。
5. 图很多就点「从这里往下讲」。它只在**这一课**里向下滚动，最多 24 屏，可随时停。讲完可以在底部追问最近一屏。

密钥只留在本机扩展存储里。课件图会发给你填写的模型接口。

## 它读什么

阅读区 `.reader-blocks` 里、当前屏幕上看得到的课件图和公式图。屏幕外的图不会一次打包送走，也不会把整门课存成文件。水印、站标和侧栏图标会跳过。
